# [Wozzeck Annotated Score](https://idmil.github.io/wozzeck-annotated)

The Wozzeck Annotated Score is a platform for viewing and contributing analysis of Alban Berg's opera *Wozzeck*. This
web viewer presents a synchronized view of:

- The full and piano-vocal scores of the opera.
- The libretto.
- Video recordings of full performances.
- Detailed annotations from René Schmidt, Serge Garant, and George Perle.
